# Контур — визуальный словарь ЧПУ

Новый интерфейс подключён в `src/main.tsx` через `TermJourney.tsx`. Только последовательный путь, уроки и повторение; прежние результаты общих тестов не удаляются.

- 24 термина / 6 уроков в `src/data/terms.ts`. Термин, отдельная SVG-иллюстрация, четыре перемешанных определения, объяснение после ответа.
- Урок считается просмотренным после ответа на все четыре термина; следующий открывается автоматически. Ошибки доступны для немедленного закрепления и последующего интервального повторения.
- Интервалы: 1 → 3 → 7 → 21 день. Ошибка сбрасывает интервал на 1 день. Досрочное правильное повторение не увеличивает интервал.
- Локальное сохранение разделено по Telegram ID. Серверная синхронизация `/api/terms` использует проверку подписи Telegram, ограничение частоты и D1. При конфликте одного термина побеждает более поздний ответ. Повторная отправка того же состояния безопасна.
- При отсутствии сети ответы остаются на устройстве. Синхронизация повторяется при восстановлении сети и каждые 30 секунд. Гостевой браузер хранит ответы только локально.
- Миграция `0003_term_memory.sql` применена к production через локальный вход Cloudflare. GitHub-токен не имеет D1-доступа (7403), поэтому миграции выполняются отдельно командой `npm run db:migrate:remote` перед публикацией Worker; обычный автодеплой остаётся прежним.
- Рисунки — кодовые SVG, внешние шрифты и изображения не нужны. Поддерживаются reduced-motion, клавиатура и безопасные отступы Telegram.

Проверки: сборка, lint, тесты интервалов/конфликтов/повреждённого кеша, проверка типов Worker и тесты подписи. Браузерное прохождение проверено на 1440, 390 и 320 px: старт, оба исхода ответа, перезапуск, продолжение и разблокировка.
